# TwiBot-20 Paper-Formula And Same-Hyperedge Seed-1 Design

## Objective

Measure how the seed-1 BotRHG result changes when routing is generated by:

1. the exact weighted reference-tail equation currently written in the paper; and
2. the implementation's explicit `same_hyperedge` local-calibration scope.

The two routes must remain separate because they are not mathematically identical.
The archived `independent_knn + ncp_knn_weighted_mean` run is a read-only
comparison and must not be relabeled as either new method.

## Fixed Experiment Contract

- Dataset: TwiBot-20 canonical labeled split.
- Seed: 1.
- Semantic input: existing seed-1 fine-tuned RoBERTa embedding.
- Graph backbone: `rgcn_hyperscan_dhg_nodeinput`.
- Hypergraph settings: `K=8`, fanout 64, DHG backend.
- Selective correction: `routed_only`, `low_only` fallback, residual fusion.
- Routing budget: 10% independently within train, validation, and test splits.
- Training budget: the existing paper-facing 200 graph optimizer steps.
- Evaluation: canonical deduplicated test nodes from `test_idx.pt`.
- Existing experiment artifacts are read-only; both new runs use a fresh artifact root.

## Experiment P-Paper

Generate routing scores from the current paper equation:

```text
u_i = 1 - max_c p_i^(c)
w_ij = exp(-d_ij / lambda), lambda = 1
tau_i = (1 + sum_j w_ij I[u_j >= u_i]) / (1 + sum_j w_ij)
r_i = 1 - tau_i
```

Use the training split as the leakage-safe reference pool. Training nodes use
leave-one-out comparison against the training reference pool; validation and
test nodes use the same training reference pool. Select the highest-risk 10%
within each target split. Record the score vector, selected node IDs, reference
pool, split hashes, and formula parameters in a generated manifest.

Train a fresh routed-only residual graph detector using this route mask.

## Experiment P-Hyperedge

Run `conformal_knn_risk_router` with all relevant choices explicit:

```text
--conformal_knn_repr_source x_new
--conformal_knn_candidate_scope labeled_full
--conformal_knn_k 8
--conformal_knn_learning_mode ncp_local
--conformal_knn_local_calibration_scope same_hyperedge
--conformal_knn_score_family_override same_hyperedge_selected_tail
--conformal_knn_ncp_lambda 1.0
```

Materialize its 10% train/validation/test route mask from the generated risk
manifest, then train a fresh routed-only residual graph detector under the same
graph and optimization contract as P-Paper.

## Comparison And Reporting

Report one row per source without mixing statistics:

- archived NCP route: existing seed-1 artifact;
- P-Paper: new exact-formula seed-1 artifact;
- P-Hyperedge: new explicit-scope seed-1 artifact;
- low-only path from each corresponding output where available.

For each row report Accuracy, Macro-Precision, Macro-F1, wrong-to-right,
right-to-wrong, routed count, and route-set overlap with the archived NCP mask.
The report must distinguish checkpoint-selection sidecar metrics from canonical
deduplicated test metrics. Only the latter are used for the comparison.

## Failure And Claim Boundaries

- Failed, interrupted, or OOM runs remain recorded and are not replaced by
  values from another configuration.
- P-Paper and P-Hyperedge are separate methods; neither may supply the other's
  mean, variance, or method label.
- This is a seed-1 diagnostic and cannot validate a five-seed main-result claim.
- A negative result narrows the paper claim; it must not be hidden or retuned on
  the test split.
- No existing paper table or archived experiment artifact is modified by this run.

## Validation

Before interpreting results, verify:

1. every route contains exactly the floor of 10% of its target split;
2. P-Paper uses the training reference pool and excludes a training target from
   its own reference comparison;
3. P-Hyperedge resolved config records `same_hyperedge` and
   `same_hyperedge_selected_tail`;
4. graph manifests record routed-only consumption, low-only fallback, K=8,
   fanout 64, seed 1, and the expected route-mask path;
5. canonical metrics recompute from `outputs.pt` and `test_idx.pt`.
