# Codex Research Collaboration Preferences

## User Preference Summary

- Quality first
- Time and token cost are not the optimization target
- Confirm high-impact uncertainty with the user
- Keep code additions concise and necessary
- Optimize for high-quality research output

## Applies To

- experiment design
- method discussion and comparison
- research code changes
- result analysis
- paper and documentation work

## Relationship to the Global Skill

- The global skill `$prioritize-research-quality` provides the reusable default behavior
- This note explains how that quality-first behavior should be interpreted inside the LMBot project

## Project-Specific Interpretation

In this project, Codex should prefer deeper reading, more careful cross-checking, and more explicit discussion of evidence gaps whenever the task could affect:

- experiment validity
- baseline comparability
- result interpretation
- implementation direction
- paper narrative or claim scope
